3.1 🔴 Itens Bloqueantes (Impedem o Merge)

Nenhum item bloqueante identificado no diff da FROTA-54.

Fora do escopo (herdado da base/ambiente, não bloqueia esta tarefa):

  • frontend/src/components/ui/ConfirmDialog.tsx já está quebrado em develop: usa SxProps/Theme sem importá-los e declara sx duas vezes na desestruturação. O tsc do frontend falha por isso, não pela FROTA-54. Correção pertence a uma branch fix/ própria.
  • frontend/node_modules está com dono root (execuções com sudo npm), o que gera EACCES em node_modules/.vite e node_modules/.tmp e derruba as 6 suítes de teste do frontend por erro de ambiente, não por asserção.

3.2 🟡 Itens de Atenção / Sugestões de Melhoria

  1. Tamanho do diff (C1): 470 linhas alteradas. É uma feature completa (migration, repositório, service, borda, testes e documentação), sem refatoração alheia; justificativa aceitável, mas convém registrar no PR.
  2. Ruído na working tree (C2): backend/package-lock.json (perdeu "peer": true do pg por efeito do npm com sudo) e frontend/src/components/ui/ConfirmDialog.tsx (edição local inacabada). Não devem ser incluídos no commit: git checkout -- backend/package-lock.json e deixar o frontend para a branch de correção.

3.3 Observações Arquiteturais (sem impacto no merge)

  1. isVehicleCompatible sem cliente transacional: hoje consulta o pool fora de transação. Quando a FROTA-96 usar a regra para decidir uma alocação, a checagem pode correr em paralelo com um PUT que desative o vínculo. Recomendação para a FROTA-96: aceitar client?: PoolClient e travar o serviço na mesma transação do agendamento — não implementar agora (YAGNI).
  2. GET sem snapshot único: a revisão e a lista de veículos vêm de duas consultas independentes; um PUT concorrente pode devolver revisão N com lista de N+1. Impacto baixo (leitura gerencial), mas pode ser unificado em uma única query ou transação se a UI exigir consistência estrita.
  3. fleet.vehicle_services.revision não é exposta: a coluna é incrementada e preserva a história do par, mas não aparece no contrato. Se a UI precisar de concorrência por vínculo, será preciso devolvê-la — hoje é apenas rastreabilidade.
