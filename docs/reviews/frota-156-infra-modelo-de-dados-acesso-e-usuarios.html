3. Achados Detalhados (Bloqueantes e Pontos de Atenção)

3.1 🔴 Itens Bloqueantes (Impedem o Merge)

🟢 Nenhum item bloqueante pendente. O apontamento C10 anterior relativo à restauração incompleta das constraints da coluna role legada no script de rollback foi integralmente resolvido no arquivo 202610180001_create_roles_permissions_and_update_users.down.sql e coberto com teste automatizado de integração (IT11).

3.2 🟡 Itens de Atenção / Sugestões de Melhoria

  1. C1/C2 — Commits atômicos no padrão Conventional Commits. As alterações estão prontas e validadas na working tree da branch feat/infra-modelo-de-dados-acesso. Recomenda-se criar commits atômicos e descritivos (ex: feat(auth): criar modelo de dados rbac e migracao de usuarios (FROTA-156) e feat(auth): implementar profile service e endpoint get profiles (FROTA-37)) antes de submeter o Pull Request para develop.
  2. C8 — Busca textual com curinga inicial na listagem de usuários. Em backend/src/repositories/users.repository.ts, o filtro opcional search utiliza LIKE '%termo%' sobre lower(name) e lower(email). Para o volume inicial da FSPH/SVO esta solução atende perfeitamente; caso a base de usuários venha a crescer consideravelmente, avaliar a criação de índice trigram GIN com a extensão pg_trgm.
