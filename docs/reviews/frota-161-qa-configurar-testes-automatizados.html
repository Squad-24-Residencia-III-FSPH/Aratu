3. Achados Detalhados (Bloqueantes e Pontos de Atenção)

3.1 🔴 Itens Bloqueantes (Impedem o Merge)

Nenhum item bloqueante identificado. Todas as invariantes arquiteturais, de concorrência e de segurança foram estritamente respeitadas.

3.2 🟡 Itens de Atenção / Sugestões de Melhoria

  • Delimitação Transacional em Migrações SQL (backend/src/database/migrator.ts:163): O método cleanMigrationSql remove comandos BEGIN; e COMMIT; externos do arquivo SQL via expressão regular para evitar advertências do PostgreSQL sobre blocos de transação aninhados (WARNING: there is already a transaction in progress). Ao adicionar novos arquivos de migração em backend/src/database/migrations/, mantenha a formatação DDL padronizada e evite scripts procedurais que manipulem transações internas não idempotentes.
  • Derivação Automática da URL de Testes (backend/tests/helpers/db-test.ts:22): A função getTestDatabaseUrl deriva a conexão de testes substituindo o banco por aratu_test a partir de DATABASE_URL caso DATABASE_URL_TEST não seja especificada no .env. Em ambientes de homologação ou CI, certifique-se de que o usuário PostgreSQL do container possua permissão de CREATEDB para a rotina de provisionamento dinâmico.
